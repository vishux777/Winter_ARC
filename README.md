# My Training — Personal Gym Companion

A mobile-first, static workout dashboard. No framework, backend, database, or build step.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a GitHub repository (for example, `my-training`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/(root)`, then Save.
6. Wait for the Pages URL shown in the Pages settings.

## Deploy with Vercel
1. Import the GitHub repository into Vercel.
2. Keep the project as a static site; no build command is needed.
3. Deploy.

## Features
- Responsive mobile layout
- Google Images search links for exercise demonstrations
- Equipment substitutions for each exercise
- Per-day exercise checklists saved in this browser's local storage
- Rest-day view and nutrition/training notes

## Notes
Exercise alternatives are general options, not one-to-one prescriptions for every injury or limitation. Choose a pain-free variation and ask a qualified coach to check technique where needed. Nutrition values in the dashboard are provisional estimates.
